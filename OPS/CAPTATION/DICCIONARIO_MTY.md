# Diccionario de agencia — MTY (editor mata el inglés de marketing)

| Lo que NO se dice al 30+ | Lo que SÍ se dice |
|---|---|
| early bird | precio de inscripción / mil pesos si se anota antes de la primera clase |
| FOMO | se llena el grupo |
| CTA | el botón / “escríbame al WhatsApp” |
| funnel | de anuncio a WhatsApp a la clase |
| masterclass (si suena a gringo) | clase en vivo / sesión |
| Lab / Lab 30d | taller de 30 días |
| n8n (frame 1) | un sistema que atiende solito |
| Telegram (si rechaza) | WhatsApp 81 4005 0088 y luego el bot |
| cupo 50 profesionales | grupo chico, 50 personas, para poder preguntar |
| hack / bro / crack | nada de eso |
| ingresos pasivos (30+) | que el trabajo repetido se haga solo |

**Roles de agencia (obligatorios, no un solo copy):**
1. **Estratega de captación** — a quién, dónde, qué oferta-puerta.
2. **Copywriter** — escribe en el idioma del alumno (gamer / side hustle / señor MTY).
3. **Editor** — borra early bird, FOMO, Teams, claims de dinero inventado.
4. **Storytelling** — identidad: creator / dueño de sistema / profesional al día.
5. **Media** — 13–17 orgánico; 18–20 ads; 20–30 Reels/WA; 30+ LinkedIn + WA.

Un creativo ≠ tres públicos. Tres campañas. Tres mesas.
