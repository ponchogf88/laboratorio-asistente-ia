# Runbook de ejecución — Cohorte 1

## T-21 a T-15: fundamento

- [ ] Definir fechas, días y hora local Monterrey.
- [ ] Elegir Zoom/Google Meet y configurar grabación con aviso previo.
- [ ] Crear landing/formulario/pago y política de reembolso.
- [ ] Confirmar cupo máximo real: 12 personas.
- [ ] Actualizar matriz de rutas oficiales y revisar enlaces.
- [ ] Aplicar paleta/branding una vez aprobados por el fundador.
- [ ] Crear lista de correo, WhatsApp o Discord con reglas y consentimiento.

## T-14 a T-8: audiencia y captación

- [ ] Publicar seis piezas de fase de curiosidad/prueba.
- [ ] Liberar lead magnet de Mapa de Credenciales.
- [ ] Responder DMs usando diagnóstico, no pitch automático.
- [ ] Registrar cada lead: profesión, meta, dolor, canal, estado.
- [ ] Agendar webinar de captación y ensayo de demo.

## T-7 a T-1: conversión y admisión

- [ ] Ejecutar webinar y enviar replay solo por ventana real definida.
- [ ] Abrir/actualizar contador de cupos con números reales.
- [ ] Revisar formulario de admisión: meta, tarea, disponibilidad, aviso de datos sensibles.
- [ ] Cobro confirmado → enviar correo de bienvenida + workbook + calendario.
- [ ] Enviar Sesión Cero: 45 min de nivelación, microdiagnóstico y elección de plantilla base.
- [ ] Crear tablero de seguimiento individual por alumno.
- [ ] Enviar recordatorio de preparar una tarea y ejemplo seguro.

## Día 0: ensayo técnico

- [ ] Verificar cámara, micrófono, grabación, subtítulos y enlaces.
- [ ] Abrir demos con datos ficticios y plan B de capturas/screenshots.
- [ ] Tener workbook, rúbrica y encuesta disponibles.
- [ ] No mostrar correos, datos de alumnos, archivos privados ni cuentas con información sensible.

## Sesiones 1 a 4: ritmo de cohorte

- [ ] Registrar asistencia.
- [ ] Entregar/grabar tarea de menos de 30 min.
- [ ] Enviar resumen en 24 h: concepto, demo, entregable y siguiente acción.
- [ ] Revisar bloqueos de ruta/herramienta sin prometer beneficios externos.
- [ ] Registrar riesgo de privacidad o uso inapropiado y reconducir a caso seguro.

## Sesión 5: Demo Day

- [ ] Enviar recordatorio 48 h antes con formato de demo de tres minutos.
- [ ] Tener checklist de evidencia por alumno.
- [ ] Facilitar presentaciones y feedback respetuoso.
- [ ] Pedir encuesta de satisfacción y autorización independiente para testimonio.
- [ ] Explicar plazo real de revisión de constancia.

## T+1 a T+14: cierre y continuidad

- [ ] Revisar evidencia y expedir únicamente constancias completas.
- [ ] Entregar carpeta/portafolio final y grabaciones conforme a política.
- [ ] Publicar resultados agregados solo con permiso: número de proyectos, no datos personales.
- [ ] Invitar al track siguiente adecuado: técnico, creativo/visual u operaciones.
- [ ] Analizar métricas: leads, conversiones, asistencia, completitud, NPS/feedback, proyectos y testimonios autorizados.

## Criterio de decisión post-cohorte

- Si hay alta asistencia y baja finalización: reducir carga/tarea y aumentar seguimiento.
- Si hay interés pero baja conversión: revisar promesa, prueba/demos y precio antes de añadir más herramientas.
- Si los alumnos piden creación visual: abrir track creator/visual.
- Si los alumnos piden integraciones: abrir track builder/operaciones con requisitos previos.
- Si predominan abogados/consultores: abrir edición vertical con casos seguros y revisión profesional.
