# Revisión externa de diseño instruccional

## Gemini — 19 de agosto de 2026

Se solicitó una crítica de la propuesta de cinco sesiones de 90 minutos para perfiles mixtos (emprendedores, estudiantes, freelancers, abogados y consultores), con asistente personal, control de herramientas/tokens, proyecto y rutas externas de credenciales.

### Riesgos señalados

1. Brecha digital amplia entre perfiles.
2. Sobrecarga cognitiva si se mezclan tokens, arquitectura y construcción sin nivelación.
3. Riesgo de que el alumno interprete rutas externas como preparación/garantía de examen oficial.
4. Necesidad de privacidad y gobernanza más explícita para profesionales regulados.
5. Evaluación difícil si cada proyecto es completamente libre.

### Cambios incorporados

| Recomendación | Implementación |
| --- | --- |
| Nivelación antes de vivo | Sesión Cero asíncrona de 45 min con glosario, seguridad y microdiagnóstico. |
| Cero fricción de diseño | Priorización de interfaces no-code/low-code; explicaciones técnicas como mapa, no como requisito. |
| Proyecto estandarizado | Tres plantillas base: Investigación/Documentos, Clientes/Proyectos y Contenido/Presencia. |
| Credenciales como ruta | Reencuadre: mapa de carrera/progreso y no preparación/garantía de certificación en 7.5 h. |
| Gobernanza obligatoria | Bloque específico en Sesión 2 y rúbrica en workbook. |

### Impacto en el programa

El curso conserva ambición práctica, pero ahora es más realizable para principiantes, más evaluable para el instructor y más seguro para abogados/consultores. Los cambios se reflejan en la Arquitectura, Temario, Prompt Maestro, Manual del Instructor, Workbook y Runbook.

## Copilot

El navegador mostró una pantalla de elección de cuenta antes de permitir la consulta. No se eligió cuenta ni se inició sesión para evitar tomar una decisión de autenticación por el usuario. La revisión de campaña mediante Copilot queda disponible cuando el usuario indique qué cuenta usar o abra una sesión autenticada.
