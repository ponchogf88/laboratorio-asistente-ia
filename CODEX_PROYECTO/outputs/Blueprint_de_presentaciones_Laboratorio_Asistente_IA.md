# Blueprint de presentaciones — Laboratorio: Crea tu Asistente Personal IA

**Formato recomendado:** 16:9, máximo 18–22 diapositivas por sesión.  
**Regla visual futura:** el sistema visual del fundador manda. Mantener por ahora una estructura de alto contraste, una idea por diapositiva, ejemplos reales y pantallas/demos como protagonistas.

## Sistema de slides reutilizable

1. Portada de sesión: número, misión y resultado tangible.
2. “Hoy vas a salir con…”: 3 entregables como máximo.
3. Hook/problema: frase grande + caso breve.
4. Concepto visual: diagrama o tabla, no párrafo.
5. Demo: captura/pantalla/flujo.
6. Taller: instrucción, tiempo y salida.
7. Cierre: evidencia + tarea de 30 minutos.

## Recursos de facilitación para integrar en las slides

- QR al workbook al inicio de cada clase.
- Diapositiva de “caso ficticio” antes de cada demo.
- Temporizador visual de taller.
- Código de color futuro: explicación / demo / taller / evidencia / alerta de seguridad.
- Una lámina de fuentes cuando haya afirmaciones verificables o rutas de proveedores.

## Notas para Canva/Slides

- Crear cinco presentaciones independientes, no una de 90 slides.
- Usar componentes reutilizables: portada, módulo, demo, ejercicio, checklist, pregunta, cierre.
- Mantener las capturas de terceros sin alterarlas y acompañarlas con fecha/fuente cuando sean educativas.
- No usar logos de proveedores como decoración del curso o anuncio sin tener el permiso/relación de marca correspondiente.
