# Matriz de rutas oficiales — Cohorte 1

**Última revisión:** 19 de agosto de 2026.  
**Regla:** esta matriz es una herramienta de orientación; cada alumno debe consultar los requisitos, idioma, precio, disponibilidad regional y políticas actuales directamente en el proveedor antes de inscribirse o pagar.

## Cómo usarla en el Laboratorio

En lugar de prometer “todas las certificaciones”, el alumno selecciona una **ruta núcleo** y una **ruta complementaria**. El proyecto del Laboratorio debe producir evidencia que haga sentido con ambas.

| Ruta | Para quién | Primera evidencia realista durante/coincidente con la cohorte | Siguiente hito |
| --- | --- | --- | --- |
| Google Skills / Developer | Quien quiere empezar con IA, cloud o agentes/builder | Perfil, labs/skill badges y bitácora de práctica, si están disponibles | Ruta GEAR / preparación para certificación Cloud según elegibilidad. |
| Microsoft Learn + Copilot | Profesional de negocio, estudiante o usuario de Microsoft 365/Copilot | Perfil, módulos/achievements y flujo aplicado a documentos/productividad | Applied Skills o certificación de fundamentos, según ruta y examen. |
| IBM SkillsBuild | Principiante que busca credencial digital compartible y aprendizaje estructurado | Módulo que ofrezca insignia + creación/configuración de Credly | Badge digital al aceptar invitación, cuando el módulo la incluya. |
| AWS Skill Builder | Persona interesada en cloud/IA aplicada, con disposición técnica progresiva | Cuenta, learning plan y módulos de fundamentos | Knowledge Badge/Cloud Quest o preparación para certificación, según plan. |
| Cisco | Perfil técnico/redes/ciberseguridad o ruta de infraestructura | Ruta de aprendizaje elegida y evidencia de progreso | Credencial/certificación conforme a requisitos propios de Cisco. |
| Coursera | Persona que necesita una especialización de universidad/empresa en un tema concreto | Selección y calendario de curso; evidencia de proyecto permitido | Certificate del curso/programa, sujeto a plan y pago/ayuda financiera. |

## Fichas para facilitar cada proveedor

### 1. Google Skills / Google Developer Program / GEAR

**Qué explicar en clase:**

- Google Skills contiene formación práctica y laboratorios; el Developer Profile reúne identidad/progreso de desarrollador.
- GEAR (Gemini Enterprise Agent Ready) se presenta actualmente como programa de rutas para agentes; su página indica 35 créditos mensuales de aprendizaje para Google Skills y paths de introducción, desarrollo, despliegue y escala de agentes. La disponibilidad está sujeta a la membresía/requisitos vigentes.
- Las *skill badges* son microcredenciales; las certificaciones de Google Cloud tienen procesos distintos y pueden requerir preparación, elegibilidad/examen u otros hitos.

**Actividad de 15 minutos:** abrir perfil, registrar el estado actual, seleccionar una ruta y añadirla a la bitácora. Si no se puede entrar a GEAR, usar una ruta pública disponible y registrar el bloqueo sin falsificar evidencia.

**Mensaje comercial permitido:** “Te ayudamos a activar y recorrer rutas oficiales de Google Skills y Google Developer, según disponibilidad y requisitos de tu cuenta.”

**No decir:** “Te garantizamos los créditos, el voucher o la certificación de Google.”

Fuentes: [GEAR](https://developers.google.com/program/gear), [Get Certified](https://developers.google.com/program/gear/getcertified).

### 2. Microsoft Learn / Copilot

**Qué explicar en clase:**

- Microsoft Learn ofrece formación sin costo; el perfil permite guardar progreso, logros y, en rutas aplicables, credenciales.
- Sus *Achievements* reconocen módulos; sus credenciales representan habilidades más amplias y pueden requerir una evaluación/examen.
- Microsoft presenta rutas relevantes para perfil de negocio, como AI Business Professional, Applied Skills para agentes y flujos con Copilot, además de fundamentos de Azure AI para tracks técnicos.

**Actividad de 15 minutos:** crear/ordenar perfil y elegir una ruta según el proyecto: productividad/negocio, IA aplicada o base cloud.

**Mensaje comercial permitido:** “Usaremos Microsoft Learn y Copilot para convertir tu flujo de trabajo en evidencia y elegir la credencial que corresponde a tu objetivo.”

**No decir:** “Este es un curso oficial de Microsoft” ni usar logos de Microsoft sin licencia/relación aplicable.

Fuentes: [Microsoft Learn Training](https://learn.microsoft.com/en-us/training/), [Student Credentials](https://learn.microsoft.com/en-us/training/student-hub/credentials), [FAQ de logros y credenciales](https://learn.microsoft.com/en-us/training/support/faq).

### 3. IBM SkillsBuild

**Qué explicar en clase:**

- IBM SkillsBuild ofrece actividades con credenciales digitales seleccionadas.
- Para las que aplican, la persona completa la actividad, recibe un correo de Credly y acepta la insignia desde su propia cuenta.
- No todos los cursos tienen la misma duración ni todas las actividades generan badge.

**Actividad de 10 minutos:** explorar credenciales por objetivo, leer duración/idioma y configurar registro de avance; explicar qué es Credly.

**Mensaje comercial permitido:** “Integramos IBM SkillsBuild como ruta para que encuentres y completes actividades que ofrezcan credenciales digitales.”

Fuente: [IBM SkillsBuild Digital Credentials](https://skillsbuild.org/adult-learners/digital-credentials).

### 4. AWS Skill Builder

**Qué explicar en clase:**

- AWS ofrece cursos, learning plans y badges; el acceso varía entre cuenta gratuita y suscripción, en especial para labs/prácticas avanzadas.
- Las AWS Knowledge Badges se logran en determinados learning plans y evaluaciones; no todos los cursos emiten badge.

**Actividad de 10 minutos:** elegir un learning plan alineado con el proyecto y marcar si es gratuito o requiere suscripción, sin pagar durante la clase.

**Mensaje comercial permitido:** “Te enseñamos a elegir una ruta de AWS Skill Builder, comprender qué evidencia ofrece y decidir si vale la inversión.”

Fuentes: [AWS Skill Builder subscriptions](https://skillbuilder.aws/subscriptions), [AWS Digital Training FAQ](https://skillbuilder.aws/support/faq/digital-training).

### 5. Cisco

**Qué explicar en clase:**

- Es una ruta posterior, especialmente útil para perfiles de redes/ciberseguridad/infraestructura.
- Las certificaciones tienen requisitos específicos. Las marcas de certificación se usan solamente bajo los términos que Cisco concede a quien las obtiene.

**Actividad de 5 minutos:** ubicar la ruta para quien realmente tenga un objetivo técnico de infraestructura; no obligar a toda la cohorte a seguirla.

Fuente: [Cisco Brand Center — Career Certification Logos](https://www.cisco.com/c/en/us/about/brand-center/logo-usage-guidelines/certification-logo.html).

### 6. Coursera

**Qué explicar en clase:**

- Es una plataforma que reúne cursos de múltiples proveedores; los certificados pueden tener precio, políticas y requisitos distintos.
- Elegirla cuando el objetivo específico justifique una especialización y no solo por acumular certificados.

**Actividad de 5 minutos:** comparar objetivo, proveedor del curso, duración, costo real y proyecto exigido. Nunca duplicar o revender contenido de la plataforma.

Fuente: [Coursera Terms](https://www.coursera.org/about/terms).

## Verificación para la constancia privada

Aceptar únicamente: enlace público de credencial, badge visible, comprobante de finalización o captura de progreso sin datos sensibles. Nunca pedir contraseña, acceso a correo, códigos de verificación o acceso a la cuenta del alumno.
